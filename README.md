💊 E-Pharmacy Price Comparison Dashboard

A modern, interactive medicine price comparison dashboard that helps users quickly find the cheapest medicine across multiple online pharmacies.

Built using Python + Streamlit, this project combines data analytics, visualization, and UI design to create a real-world healthcare use case.

⸻

🚀 Live Preview

📍 Runs locally on: http://localhost:8501
📊 Clean, responsive dashboard with images, pricing insights, and best-deal detection.

⸻

✨ Features

✅ Search any medicine (e.g., cough syrup)
✅ Compare prices across multiple stores
✅ Highlight the cheapest option automatically 🏆
✅ Product image preview
✅ Direct buy link for best deal
✅ Clean, professional UI
✅ Scalable for real APIs

⸻

📊 Dashboard Sections

🔎 Search Panel
	•	Enter medicine name
	•	Choose number of comparison options
	•	One-click price comparison

🏆 Best Price Highlight
	•	Shows the cheapest medicine automatically
	•	Displays:
	•	Product image
	•	Store name
	•	Title
	•	Price
	•	Buy link

📦 All Options View
	•	Shows multiple store options
	•	Useful for decision making
	•	Can be extended with:
	•	Ratings
	•	Delivery time
	•	Discounts

2️⃣ Install dependencies
