## 🌟 Overview

Medicine prices can vary significantly across different online pharmacies. This dashboard empowers users to:

- 💰 **Save money** by finding the best deals
- ⚡ **Compare instantly** across multiple platforms
- 🧠 **Make informed decisions** with clear pricing insights

Built using **Python** and **Streamlit**, this project combines data analytics, visualization, and UI design to create a real-world healthcare solution that's both practical and scalable.

---

## ✨ Features

✅ **Smart Search** - Search any medicine (e.g., cough syrup, pain relievers)  
✅ **Multi-Store Comparison** - Compare prices across multiple online pharmacies  
✅ **Best Deal Detection** - Automatically highlights the cheapest option 🏆  
✅ **Product Previews** - View product images for better decision-making  
✅ **Quick Purchase** - Direct buy links for the best deals  
✅ **Clean UI** - Professional, responsive interface  
✅ **Scalable Architecture** - Ready for integration with real pharmacy APIs

## 📊 Dashboard Sections

### 🔎 Search Panel
- Enter medicine name

### 🏆 Best Price Highlight

- Price
- Direct buy link

### 📦 All Options View

## 🚀 Installation

### Prerequisites
- Python 3.8 or higher
- pip package manager

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/princesi22/E-pharmacy-price-comparison.git
   cd E-pharmacy-price-comparison
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**
   ```bash
   streamlit run app.py
   ```

4. **Access the dashboard**
   
   Open your browser and navigate to:
   ```
   http://localhost:8501
   ```

---

## 💻 Usage

1. **Launch the app** using the installation steps above
2. **Enter a medicine name** in the search panel
3. **Select the number of options** you want to compare
4. **Click "Compare Prices"** to view results
5. **Review the best deal** highlighted at the top
6. **Click the buy link** to purchase at the lowest price
